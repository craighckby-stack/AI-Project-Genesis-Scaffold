GitHub Bulk Privacy Tool

Securely change your public repositories to private directly from your browser.

How to use:

  1. Go to GitHub -> Settings -> Developer settings -> Personal access tokens (classic).
  2. Generate a new token with the repo scope checked.
  3. Paste the token below. (Your token never leaves your browser).

Public Repositories

Enter your token and click "Fetch Repos" to see your public repositories.
