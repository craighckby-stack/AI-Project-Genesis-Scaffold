# ARCHITECTURE THEME: DARLEK CANN v3.0

## Design Philosophy
- **Quantum Minimalism**: High-density information display with low-cognitive-load aesthetics.
- **Neural-Pulse Feedback**: UI elements respond to state changes via subtle glow animations.
- **Glass-Orchestration**: Layered depth using backdrop-filters to maintain context during multi-agent task execution.

## Color Palette
- Primary: #020617 (Void)
- Secondary: #050a1f (Deep Space)
- Accent: #06b6d4 (Neural Cyan)

## Implementation Guidelines
- All new components MUST implement `.glass-panel` for containerization.
- Use `var(--ease-quantum)` for all transitions to ensure fluid agent-state updates.
