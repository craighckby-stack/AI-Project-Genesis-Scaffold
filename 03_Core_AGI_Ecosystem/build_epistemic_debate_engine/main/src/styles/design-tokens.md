# Design System Architecture: DARLEK CANN v3.0

## Core Philosophy
- **Quantum-Ease**: All transitions utilize `cubic-bezier(0.22, 1, 0.36, 1)` to mimic biological neural firing patterns.
- **Holographic Depth**: Z-index management and backdrop-blur are strictly enforced to maintain the 'System-Book' aesthetic.
- **Diagnostic Integrity**: The `diagnostic-frame` acts as a global visual boundary for agent-swarm activity.

## Integration Schema
- Use `.holographic-panel` for all container-level agent nodes.
- Use `.btn-quantum` for all user-triggered state mutations.
- Use `.terminal-output` for logging internal agent reasoning chains.
