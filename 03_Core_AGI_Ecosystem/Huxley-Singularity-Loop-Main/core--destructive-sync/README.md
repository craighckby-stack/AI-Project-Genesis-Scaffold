### 2. Autonomous Branching
Ensures code safety by programmatically creating a backup reference before performing a distillation.

```typescript
export const createBranch = async (owner, repo, newBranch, baseBranch, token) => {
  const baseRef = await ghFetch(`/git/refs/heads/${baseBranch}`, token);
  const sha = (await baseRef.json()).object.sha;
  return ghFetch(`/git/refs`, token, {
    method: 'POST',
    body: JSON.stringify({ ref: `refs/heads/${newBranch}`, sha })
  });
};
```
