# N-Body Gravitational Simulator

A highly polished, interactive real-time N-Body Gravitational Simulator built with Next.js, Tailwind CSS, and HTML5 Canvas. Inspired by cosmic mechanics and compiled under Dalek Caan's Cyber Slate aesthetic.

## Key Features
- **Real-time Physics Engine**: High-precision sub-stepping Euler-Cromer integration.
- **Interactive Canvas**: Zoom, pan, auto-center of mass tracking, and custom body placement.
- **Presets**: Solar System, Binary Stars, and Chaotic Three-Body configurations.
- **Live Metrics**: Real-time kinetic, potential, and total energy tracking with Recharts.
- **Custom Body Creator**: Add, edit, or remove celestial bodies with custom mass, velocity, and color.
