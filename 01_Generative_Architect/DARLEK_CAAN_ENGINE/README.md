## 🌌 Overview
**Darlek Caan v3.2** is an advanced, autonomous code evolution control plane and interactive agent orchestrator, built on top of Next.js 15+, Tailwind CSS v4, and React 19. It is designed to act as a self-enhancing code-evolution engine that continuously inspects, debates, refactors, and deploys structural optimizations to its own repository. 

Originally inspired by the dualism of chess structures, Darlek Caan has mutated into a full-scale **Sovereign Code Evolution Platform** that performs multi-cycle autonomous refactoring, siphons patterns from elite developer ecosystems, and ensures strict JSDoc semantic health across the codebase.

## 🚀 Key Evolutionary Features

### 1. 🏗️ Architectural Genesis Pass (Cycle 1)
To ensure long-term codebase legibility and contextual persistence for multi-turn AI interventions, the system dedicates its exact first evolution cycle (`evolutionCycle === 1`) exclusively to the **Architectural Genesis Pass**.
- Scans all active `.ts` and `.tsx` source files.
- Generates high-fidelity JSDoc headers explaining the file's purpose, architectural connectivity, and system-wide interactions.
- Integrates these comments at the very top of each file without introducing functional mutations.

### 2. ⚖️ Multi-Agent Swarm & Debate Orchestration
Every proposed mutation undergoes rigorous validation by an autonomous Agent Orchestra. 
- **Perspectives**: Critic personas with diverse priorities (architectural elegance, type safety, performance, and security) review every proposal.
- **Synthesizer Resolution**: Concerns raised in the debate are merged and resolved in real time by the Synthesizer Engine to output perfect, battle-tested code.
- **Architectural Exemption**: During Cycle 1, the agents enforce the *Architectural Genesis* rules, bypassing standard refactoring debates to guarantee stable header ingestion.

### 3. 🌀 Global Repository Siphoning
The engine features a **Global Siphon Conduit** that fetches, analyzes, and adapts design patterns, layout ideas, and high-value structures from elite public and private code spaces:
- **Global Repositories**: Microsoft, Google, DeepMind, IBM, Firebase, and Vercel.
- **Companion Repositories**: The user's active portfolio projects.
- Extracted design wisdom is merged directly into current evolution proposals.

### 4. 🧠 Transactional Safety & Memory Loops
- **Database Mutation History**: Retrieves the most recently applied database mutations via active `sessionId` to build a chronological memory block.
- **Zero-Truncation Mandate**: Standardized prompts and increased input/output limits (up to 35,000 characters) ensure code is never output with placeholder comments like `// ... rest of code`.
- **Atomic Backups**: Creates temporary snapshots in `.evolve_backups` to guarantee transactional safety during complex self-updates.

## ⚙️ Setup & Execution

### 1. Environment Configuration
Create a `.env` or `.env.local` file at the project root and provide your Gemini API key:
```env
GEMINI_API_KEY=your_gemini_api_key_here
NEXT_PUBLIC_GEMINI_API_KEY=your_gemini_api_key_here
```

### 2. Installation & Build Dependencies
To build and verify the application, run:
```bash
# Install NPM packages
npm install

# Build the Next.js standalone application
npm run build
```

### 3. Start Development Server
Launch the development environment:
```bash
npm run dev
```
The application will spin up at **http://localhost:3000** (or your container's mapped proxy port).
