# DARLEK CANN v3.0 Architectural Blueprint

## Core Philosophy
- **Agent Orchestra**: Decentralized task execution via LLM-fallback layers.
- **Epistemic Integrity**: Enforced via Zod schema validation at the edge.
- **Quantum State Management**: Utilizing React-Three-Fiber for 3D visualization of system entropy.

## Workflow
1. **Ingestion**: Raw data enters via `firebase` streams.
2. **Processing**: `genai` orchestrates logic across 3 tiers (Fast/Balanced/Deep).
3. **Visualization**: `three.js` renders the system state.

## Integration Schema
- **Frontend**: Next.js/Vite Hybrid.
- **State**: Firebase Realtime + Local Zod-validated stores.
- **Styling**: Tailwind CSS v4 (JIT-compiled).
