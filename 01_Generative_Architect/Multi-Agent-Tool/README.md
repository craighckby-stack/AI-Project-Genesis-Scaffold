# Multi-Agent Application (Prism)

This is a multi-agent AI system built using React, Express, Vite, and Google Gemini API. It provides a specialized chat interface that queries multiple distinct AI "personas" concurrently, synthesizing their unique perspectives into a singular comprehensive answer.

## Features

- **Multi-Persona Echo Chamber**: Simultaneously query distinct AI personas (Theoretical Physicist, Analytical Mathematician, Systems Architect, etc.).
- **Synthesis Engine**: Uses `gemini-3.1-pro-preview` to aggregate and synthesize persona outputs into a well-reasoned, highly technical final response.
- **File Attachments & Context**: Allows users to attach files or provide a GitHub Repository (via Repo name and optional Token) to be included in the context of the synthesis.
- **Markdown & Math**: Supports full markdown rendering, including GitHub Flavored Markdown (tables, codeblocks).
- **Firebase Integration**: Stores chat sessions, messages, and state in Firestore using Firebase anonymous authentication.
- **Thinking Process**: Reveals the hidden reasoning (thinking trace) generated by the Gemini Pro model.

## Setup

1. **Clone the repository**
2. **Install dependencies**: `npm install`
3. **Set up Environment Variables**: Create a `.env` file referencing `.env.example` and add your `GEMINI_API_KEY`.
4. **Firebase Configuration**: Setup Firebase project and Firestore (ensure you enable Anonymous Auth). Add your firebase config via the environment variables or `firebase-applet-config.json`.
5. **Run the development server**: `npm run dev`

## Architecture

- **Frontend**: React (Vite), Tailwind CSS, Lucide Icons, React Markdown.
- **Backend**: Express + Node.js (with Vite middleware in dev). Handles API proxying and GitHub ZIP downloads.
- **Database**: Firebase Firestore.
- **AI Models**: 
  - `gemini-3.5-flash` for initial fast persona deliberations.
  - `gemini-3.1-pro-preview` for final deep synthesis and reasoning.
