## 🔍 Diagnostic Checklist First

Before opening a support request, please complete this simple self-triage checklist:
1. **Reset Database State**: If you hit a malformed disk image error, wipe corrupt locks manually:
   ```bash
   rm prisma/dev.db*
   npx prisma db push
   ```
2. **Key Check**: Run `curl` or test outside to verify `GEMINI_API_KEY` is fully activated and has proper quota.
3. **Check Linter Errors**: Run `npm run lint` locally; any syntax issues in files can cause the virtual Coherence Gate memory to fail compile cycles and reject proposals.
