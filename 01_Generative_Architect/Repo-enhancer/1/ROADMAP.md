# 🗺️ DARLEK CANN — Product Roadmap

This roadmap documents our milestones and the master plan for the evolution of the DARLEK CANN multi-agent code mutation reactor.

---

## 🟢 Phase 1: Foundation & Sandboxing (Completed)
- [x] **Adversarial Debate Chamber**: Established multi-agent adversarial evaluation (Security Specialist, Optimizer, Realist) with dynamic, multi-turn dialogue.
- [x] **Coherence Gate Integration**: Live virtual memory dry-runs, TypeScript compiler checks, and automated formatting gates.
- [x] **Interactive Dashboard**: Modern dark-mode neon dashboard with immediate manual overrides, history feeds, and visual diff selectors.
- [x] **Dynamic Risk-Scoring**: Automated structural complexity scoring (`1-10`) before mutation approval.

## 🟡 Phase 2: Operator Customization (Current)
- [x] **Risk-Capped Auto-Approve**: Enable automated approvals up to low, medium, or high risk levels with strict manual checkpoints.
- [x] **Debate Range Customization**: Added quick selector presets for **5**, **10**, or **20** debate cycles to fine-tune sub-agent reasoning before decisions.
- [x] **Self-Healing SQLite Driver**: Proactive lock-breaking, automatic clean-ups, and corruption recovery for standard runtime sqlite DB storage.
- [ ] **Custom Agent Creation**: Custom prompts for adding regional domain-expert agents dynamically.

## 🔵 Phase 3: Autonomous Workspace Scaling (Q3 - Q4 2026)
- [ ] **Multi-Repo Co-Evolution**: Allow the reactor to open cross-repository mutations to sync packages and library API upgrades.
- [ ] **Dynamic Grounding**: Automatic indexing of local wikis, project documentation, and issues to inform sub-agent debate panels with deep contextual clues.
- [ ] **Semantic Diff Summarizers**: Automatic generation of precise changelogs and changelists powered by Gemini models post-mutation.

## 🔴 Phase 4: Decentralized Evolution (2027)
- [ ] **Autonomous Pull Request Workflows**: Complete integration inside GitHub Actions backends, where DARLEK CANN automatically clones forks, analyzes PR quality, runs multi-agent debates, and commits fixes autonomously.
- [ ] **Consensus over Distributed Keys**: Distributed agent cryptographic verification for automated branch approvals.
