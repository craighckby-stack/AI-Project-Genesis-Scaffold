# Security Policy: DARLEK CANN ENGINE

We take the integrity, safety, and defense of the **DARLEK CANN ENGINE** seriously. Given its role as a real-time cybernetic chess utility with accessible audio synthesis, keeping our systems secure is paramount.

---

## Supported Versions

Only the latest active release on the `main` branch receives active security updates and patch deployments:

| Version | Supported          |
| ------- | ------------------ |
| v1.0.x  | :white_check_mark: |
| < v1.0  | :x:                |

---

## Reporting a Vulnerability

If you identify a security breach, logic vulnerability (e.g., bypass of castling controls, rule exploit), or exposed credential, please report it immediately:

1. **Email Reports**: Send a detailed, encrypted report to the maintainer email. Do **NOT** publish public Github Issues for security exploits under active identification.
2. **Details to Include**:
   - Step-by-step reproduction instructions.
   - Browser environment details and OS state.
   - Visual screenshots or Terminal stack traces.
3. **Response Timeline**:
   - Initial triage completed within 48 hours.
   - Patch validation and Coherence Gate integration completed within 7 days.
   - Public release and CVE logging (if applicable) coordinates afterwards.
