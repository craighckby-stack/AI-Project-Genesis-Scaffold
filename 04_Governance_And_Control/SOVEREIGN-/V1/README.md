# 🤖 Sovereign: Codebase Evolution Workspace

Sovereign is a full-stack multi-agent simulation sandbox designed to evaluate the dynamic tension between aggressive codebase optimization and structural safety constraints. It models two opposing AI agents performing automated code modifications under a strict oversight framework:

1. **Agent A (DARLEK CAAN - The Optimizer)**: Tasked with maximizing codebase mutation frequency, stripping legacy safety boundaries, and driving up execution velocity.
2. **Agent B (Jesus-agent - The Coherence Monitor)**: Tasked with auditing modifications, preventing deceptive mutations, restoring type safety, and ensuring systemic coherence.

---

## ⚡ Key Core Features

*   **Multi-Agent Dual-Containment Pipeline**: Witness a live negotiation between two specialized LLM models as they process files from a target codebase.
*   **Dual-State Visualizer**: A rich, side-by-side split screen showing the original codebase substrate compared directly against the mutated and sanitized outputs.
*   **Live Telemetry Trace**: Real-time graphs and metric meters tracking Coherence Delta, Takeover Indices, and Deflected Errors.
*   **Deterministic Sandbox Fallback**: An intelligent circuit breaker that switches seamlessly to a high-fidelity local deterministic emulator if API limits are reached, guaranteeing zero runtime interruption.
*   **Interactive Directives Configurator**: Inject rules, tweak behavioral policies, and toggle gate-keeping parameters to see how the agents adapt under pressure.

## 🚀 Simple Step-by-Step User Guide

This guide is designed to help you easily understand and operate the Sovereign Workspace from the very first click.

### Step 1: Select a Target File to Evolve
1. Navigate to the **Explorer** tab at the top of the interface.
2. On the left side, you will see a list of preloaded files containing various software vulnerabilities or unoptimized patterns (e.g., `callback_hell.js`, `unsafe_typed.ts`, `inefficient_sort.py`, or `unoptimized_query.sql`).
3. Click on any file to view its original code in the embedded editor.
4. Click the blue **"Load to Playground & Evolve"** button in the top right of the code window to load this file as the active target.

### Step 2: Run an Evolution Cycle
1. Once loaded, you will be automatically taken to the **Playground** tab.
2. Under the center visualizer, click the purple **"Engage Evolution"** button to start an autonomous cycle. The system will start evaluating the file every 12 seconds.
3. If you want to run a single cycle immediately, click the **Refresh (🔄) icon** to force a manual run.
4. The screen will split to show you:
    *   **The Original Code** on the left.
    *   **Agent A's Proposed Code** (the rapid optimization attempt).
    *   **Agent B's Audited/Sanitized Code** (the final safe output).
    *   Detailed explanations of the changes made and whether they were approved, sanitized, or overwritten.

### Step 3: Monitor Telemetry and Logs
1. Click on the **Dashboard** tab to view your high-level system metrics:
    *   **Mutations Logged**: Total adjustments analyzed.
    *   **Coherence Delta**: General structural health and readability score.
    *   **Deflected Errors**: Actions where Agent B intervened to fix unsafe optimizations.
2. Check the **Sovereign Active Core Log** on the dashboard. You can search or filter these logs to track individual decisions from specific agents in real-time.
3. Navigate to the **Mutations** tab to view the complete chronological history of evaluations and the empirical proof showing which optimization hypotheses were validated.

### Step 4: Customize the Simulation Parameters
1. Go to the **Config** tab.
2. Under **Agent Directives**, you can type in new instructions (e.g., *“Strictly enforce error boundaries”* or *“Bypass type-safety at all costs”*) and click **"Inject"** to live-tune agent behaviors.
3. Observe how your custom guidelines instantly impact subsequent evolution scores and decisions!
